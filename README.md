## About

I learn by building AI-native systems, with agents as teammates.

I'm exploring how agents use tools, check their work, and carry useful experience into the next task. I'm especially interested in memory and skills—not just how to store them, but how to tell whether they actually help.

Outside agent systems, my interests include self-hosted infrastructure and Minecraft engineering automation.

## How I build

- **Set the direction.** Make goals, constraints, and task boundaries clear; let agents plan and act within them.
- **Check the work.** Use testing, evaluation, and human review to understand what worked and what still needs attention.
- **Carry useful lessons forward.** Turn experience into reusable memory and skills, then check whether they help on later tasks.
